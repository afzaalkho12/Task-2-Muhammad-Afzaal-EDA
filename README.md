# Exploratory Data Analysis (EDA) - Project 2

## Project Overview

This project performs Exploratory Data Analysis (EDA) on an e-commerce dataset using Python. The objective is to clean the dataset, explore customer purchasing behavior, identify trends, detect outliers, and generate meaningful business insights through statistical analysis and data visualization.

---

## Project Objectives

- Understand the dataset structure.
- Clean and preprocess the data.
- Handle missing values.
- Perform descriptive statistical analysis.
- Explore customer purchasing behavior.
- Analyze revenue trends.
- Detect outliers.
- Identify correlations among numerical variables.
- Generate business insights and recommendations.

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- SciPy
- OpenPyXL
- Jupyter Notebook

## Key Findings

- Customer orders vary across different months.
- Revenue fluctuates over time.
- Certain products contribute significantly to sales.
- Customers prefer specific payment methods.
- Referral sources impact customer acquisition.
- Coupon usage differs among customers.
- Strong relationships exist between some numerical variables.
- A few outliers represent unusually large purchases.

## Conclusion

The exploratory data analysis provides valuable insights into customer behavior, sales performance, and operational trends. These findings can help businesses improve decision-making, optimize inventory, and enhance marketing strategies.
